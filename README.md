## 六、部署建議

### 方案一：GitHub Pages（免費）
1. 在 GitHub 建立新 Repository（例如 `woer-dental`）
2. 將 `woer-dental-website` 資料夾內所有檔案上傳
3. 前往 Settings > Pages，選擇主分支作為來源
4. 網站將自動部署至 `https://[username].github.io/woer-dental/`

**優點**：完全免費、自訂域名支援、SSL憑證自動配置

### 方案二：Netlify（免費）
1. 註冊 Netlify 帳號
2. 將網站資料夾拖曳至 Netlify 部署介面
3. 自動獲得 `https://[site-name].netlify.app/` 網址
4. 可綁定自訂域名

**優點**：部署簡單、全球CDN加速、自動HTTPS

### 方案三：Vercel（免費）
1. 註冊 Vercel 帳號
2. 匯入 GitHub Repository 或直接上傳資料夾
3. 自動部署並提供 HTTPS

**優點**：效能優秀、適合靜態網站

### Google Maps 連結導流設定
1. 取得網站網址後，登入 Google 商家檔案
2. 在「網站」欄位填入網站URL
3. 在「貼文」功能中分享網站連結，引導患者瀏覽專業內容
